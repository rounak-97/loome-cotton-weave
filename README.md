# loomé. — A Cotton Weave

A minimalist e-commerce product page built with HTML, CSS, and vanilla JavaScript, focused on layered UI composition with CSS positioning.

**Live Demo:** [https://your-app.vercel.app](https://your-app.vercel.app)

## Features

- Layered product card with floating price, rating, and call-to-action overlays (`position: relative` / `absolute`)
- Interactive thumbnail gallery that updates the main product preview
- Three-column editorial grid paired with custom serif and sans-serif typography
- Lightweight vector iconography via Remix Icon

## Tech Stack

- HTML5
- CSS3 (Grid, Flexbox, Positioning)
- Vanilla JavaScript
- Remix Icon & Google Fonts
